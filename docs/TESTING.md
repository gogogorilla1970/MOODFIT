# Testing v0.2

1. Build and install the debug APK.
2. Select a clear adult face photo under YOU.
3. Select an outfit/look reference under LOOK.
4. Enter a fal.ai API key for the current session.
5. Choose which attributes to preserve from LOOK.
6. Tap Create Makeover and wait for the FLUX.2 queue result.
7. Verify recognizable identity, requested look attributes, realistic anatomy, and that the result preview loads.

For best identity fidelity, use a well-lit, front-facing face reference without sunglasses or heavy occlusion.
